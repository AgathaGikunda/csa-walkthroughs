Game 2022 FRQ 1

The classes

A one-player video game has three levels. A player tries to reach the goal in each level. Each level is a Level object.

public class Level
{
    /** Returns true if the player reached the goal on this level, false otherwise */
    public boolean goalReached()
    { /* implementation not shown */ }

    /** Returns the number of points earned on this level */
    public int getPoints()
    { /* implementation not shown */ }
}
public class Game
{
    private Level levelOne;
    private Level levelTwo;
    private Level levelThree;

    /** Returns true if this game is a bonus game, false otherwise */
    public boolean isBonus()
    { /* implementation not shown */ }

    /** Simulates playing one game. After it runs, the three levels
     *  and isBonus() describe the game just played. */
    public void play()
    { /* implementation not shown */ }

    /** Returns the score of the game most recently played, part (a) */
    public int getScore()
    { /* to be implemented in part (a) */ }

    /** Plays num games and returns the highest score, part (b)
     *  Precondition: num > 0 */
    public int playManyTimes(int num)
    { /* to be implemented in part (b) */ }
}

(a) getScore

The score counts levels in order, and only while the player keeps reaching the goal:

  • If the player reached the goal in level one, add level one's points.
  • Only if level one's goal was reached: if level two's goal was reached, add level two's points.
  • Only if level two's goal was reached: if level three's goal was reached, add level three's points.
  • Then, if the game is a bonus game, the score is tripled.

Show part (a) solution
public int getScore()
{
    int score = 0;
    if (levelOne.goalReached())
    {
        score += levelOne.getPoints();
        if (levelTwo.goalReached())
        {
            score += levelTwo.getPoints();
            if (levelThree.goalReached())
            {
                score += levelThree.getPoints();
            }
        }
    }
    if (isBonus())
    {
        score *= 3;
    }
    return score;
}
Show part (b) solution
public int playManyTimes(int num)
{
    play();
    int best = getScore();            // the first game is the starting best
    for (int i = 2; i <= num; i++)
    {
        play();                       // play first, then read the score
        int score = getScore();
        if (score > best)
        {
            best = score;
        }
    }
    return best;
}

WordMatch 2021 FRQ 1

About this version. This is the real AP question rewritten in our own words, with our own examples. The class, the methods and the task are the same as on the exam, so the official scoring guidelines still apply.

The class

A word game stores a secret word. Players make guesses, and each guess gets a score that depends on how often it appears inside the secret word.

public class WordMatch
{
    /** The secret string, all lowercase letters */
    private String secret;

    /** Returns the score for guess, as described in part (a)
     *  Precondition: 0 < guess.length() <= secret.length() */
    public int scoreGuess(String guess)
    { /* to be implemented in part (a) */ }

    /** Returns the better of two guesses, as described in part (b)
     *  Precondition: guess1 and guess2 are lowercase and different */
    public String findBetterGuess(String guess1, String guess2)
    { /* to be implemented in part (b) */ }
}

(a) scoreGuess

The score is: how many times guess appears in secret, multiplied by the length of guess, squared. Appearances may overlap.

For these examples, secret is "banana".

Return whichever guess has the higher score from scoreGuess. If both scores are equal, return the guess that is alphabetically greater. Assume scoreGuess works, whatever you wrote in part (a).

Show part (a) solution
public int scoreGuess(String guess)
{
    int count = 0;
    int len = guess.length();
    for (int i = 0; i <= secret.length() - len; i++)
    {
        if (secret.substring(i, i + len).equals(guess))
        {
            count++;
        }
    }
    return count * len * len;
}
Show part (b) solution
public String findBetterGuess(String guess1, String guess2)
{
    int score1 = scoreGuess(guess1);      // part (a) method: no dot
    int score2 = scoreGuess(guess2);
    if (score1 > score2)
    {
        return guess1;
    }
    if (score2 > score1)
    {
        return guess2;
    }
    if (guess1.compareTo(guess2) > 0)     // tie: alphabetically greater wins
    {
        return guess1;
    }
    return guess2;
}

Feeder 2024 FRQ 1

About this version. This is the real AP question rewritten in our own words, with our own examples. The class, the methods and the task are the same as on the exam, so the official scoring guidelines still apply.

The class

A bird feeder holds food, measured in grams. Each day, birds come to eat, or, rarely, a bear comes and eats everything.

public class Feeder
{
    /** Grams of food in the feeder; always >= 0 */
    private int currentFood;

    /** Simulates one day with numBirds birds or possibly a bear,
     *  as described in part (a). Precondition: numBirds > 0 */
    public void simulateOneDay(int numBirds)
    { /* to be implemented in part (a) */ }

    /** Simulates up to numDays days and returns the number of days
     *  birds or a bear found food, as described in part (b)
     *  Preconditions: numBirds > 0, numDays > 0 */
    public int simulateManyDays(int numBirds, int numDays)
    { /* to be implemented in part (b) */ }
}

(a) simulateOneDay

  • 95% of days are normal. Every bird eats the same random amount of food, a whole number of grams from 10 to 50 inclusive. If the birds want more food than the feeder holds, they empty it (currentFood becomes 0). Otherwise the food they eat is taken away.
  • 5% of days, a bear comes and empties the feeder: currentFood becomes 0.

(b) simulateManyDays

Simulate one day at a time, for up to numDays days, using simulateOneDay. Stop early as soon as the feeder is empty, because no later day can have food. Return how many days started with food in the feeder (currentFood greater than 0). Assume simulateOneDay works, whatever you wrote in part (a).

Check your answers

Write both parts by hand first, then open each solution and compare. Other correct solutions exist: trace yours with the examples.

Show part (a) solution
public void simulateOneDay(int numBirds)
{
    if (Math.random() < 0.05)                      // 5% chance: a bear
    {
        currentFood = 0;
    }
    else
    {
        int each = (int) (Math.random() * 41) + 10;   // 10 to 50 grams
        int eaten = numBirds * each;
        if (eaten > currentFood)
        {
            currentFood = 0;
        }
        else
        {
            currentFood -= eaten;
        }
    }
}
Show part (b) solution
public int simulateManyDays(int numBirds, int numDays)
{
    int days = 0;
    while (days < numDays && currentFood > 0)
    {
        simulateOneDay(numBirds);    // part (a) method: no dot
        days++;
    }
    return days;
}

AppointmentBook 2023 FRQ 1

About this version. This is the real AP question rewritten in our own words, with our own examples. The class, the methods and the task are the same as on the exam, so the official scoring guidelines still apply.

The class

Students book appointments with a teacher. The school day has periods 1 to 8, and each period has 60 minutes, numbered 0 to 59. An appointment uses a block of consecutive free minutes inside one period.

public class AppointmentBook
{
    /** Returns true if minute in period is free, false otherwise
     *  Preconditions: 1 <= period <= 8; 0 <= minute <= 59 */
    private boolean isMinuteFree(int period, int minute)
    { /* implementation not shown */ }

    /** Marks duration minutes in period as taken, starting at startMinute
     *  Preconditions: 1 <= period <= 8; 0 <= startMinute <= 59;
     *                 1 <= duration <= 60; those minutes are free */
    private void reserveBlock(int period, int startMinute, int duration)
    { /* implementation not shown */ }

    /** Returns the first minute of the earliest block of duration free
     *  minutes in period, or -1, as described in part (a)
     *  Preconditions: 1 <= period <= 8; 1 <= duration <= 60 */
    public int findFreeBlock(int period, int duration)
    { /* to be implemented in part (a) */ }

    /** Books an appointment as described in part (b) and returns true,
     *  or returns false if none could be booked
     *  Preconditions: 1 <= startPeriod <= endPeriod <= 8; 1 <= duration <= 60 */
    public boolean makeAppointment(int startPeriod, int endPeriod, int duration)
    { /* to be implemented in part (b) */ }
}

(a) findFreeBlock

Find the earliest block of duration free minutes in a row in period, and return its first minute. Return -1 if there is none. Use isMinuteFree. This method books nothing.

In these examples, period 2 looks like this: minutes 0–9 taken, 10–24 free, 25–29 taken, 30–59 free.

Show part (a) solution
public int findFreeBlock(int period, int duration)
{
    int inARow = 0;
    for (int minute = 0; minute <= 59; minute++)
    {
        if (isMinuteFree(period, minute))
        {
            inARow++;
            if (inARow == duration)
            {
                return minute - duration + 1;   // where the block started
            }
        }
        else
        {
            inARow = 0;                         // the streak is broken
        }
    }
    return -1;
}
Show part (b) solution
public boolean makeAppointment(int startPeriod, int endPeriod, int duration)
{
    for (int period = startPeriod; period <= endPeriod; period++)
    {
        int start = findFreeBlock(period, duration);
        if (start != -1)
        {
            reserveBlock(period, start, duration);
            return true;
        }
    }
    return false;                               // only after every period
}

Show part (a) solution
public static int numberOfLeapYears(int year1, int year2)
{
    int count = 0;
    for (int year = year1; year <= year2; year++)
    {
        if (isLeapYear(year))
        {
            count++;
        }
    }
    return count;
}
Show part (b) solution
public static int dayOfWeek(int month, int day, int year)
{
    int first = firstDayOfYear(year);
    int n = dayOfYear(month, day, year);
    return (first + n - 1) % 7;
}
