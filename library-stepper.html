Question 2: Library Books

For each part, you write a code segment (no method header) that uses the variables given and prints the intended output. Your code must work for every example in the table, and for any other values that follow the rules. You may use any method in the Java Quick Reference.

This question involves writing two code segments that use information about books in a school library. The library uses the following variables to keep information about each book.

  • bookId is an int variable that represents the book's catalog number. Assume the value of this variable is positive and has at least two digits.
  • bookInfo is a String variable that contains information about the book. The string consists of the author's last name, followed by a colon (":"), followed by the book title, followed by another colon, followed by the year the book was published. Assume that no other colons appear in the string.

2a

A code segment, which you will write, should determine whether the ones digit of bookId is larger than every other digit in the number. If so, the code segment should print "largest"; otherwise, it should print "not largest".

  • If bookId is 23419, the segment prints "largest" because the ones digit, 9, is larger than 2, 3, 4 and 1.
  • If bookId is 5925, the segment prints "not largest" because the 9 is larger than the ones digit, 5.
  • If bookId is 5455, the segment prints "not largest" because another 5 is equal to the ones digit, so the ones digit is not larger than every other digit.

2b

A code segment, which you will write, should process the string bookInfo and print the book title followed by the year in parentheses, with one space between the title and the opening parenthesis.

  • If bookInfo is "Okafor:The Long Road:2019", the segment prints "The Long Road (2019)".
  • If bookInfo is "Lee:Stars:2003", the segment prints "Stars (2003)".
