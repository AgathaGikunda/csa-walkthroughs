(a) generateUsername (4 points)

Write the generateUsername method, which returns an available username for a student with first name first and last name last.

The base username is the first letter of first followed by all of last. For example, the base username for "jordan" and "lee" is "jlee".

  • If the base username is not taken, the method returns the base username.
  • If the base username is taken, the method tries adding the number 1 to the end of the base username, then 2, then 3, and so on. It returns the first of these that is not taken.

The helper method isTaken must be used to decide whether a username is available. Assume that an available username will always eventually be found.

Assume the following usernames are already taken: "jlee", "jlee1", "mrivera", "aking", "aking1", "aking2".

(b) maskEmail (3 points)

Write the maskEmail method, which returns a version of email that hides most of the part before the "@".

The returned string keeps the first character of email. Every other character that comes before the "@" is replaced by an asterisk ("*"). The "@" and every character after it stay the same.
