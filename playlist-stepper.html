(a) songsThatFit

Write the songsThatFit method. The playlist plays songs in order, starting with song 1. The method returns how many songs can be played completely without the total time going over maxSeconds. The method stops at the first song that does not fit, even if a later song is shorter. If every song from 1 to numSongs fits, the method returns numSongs.

Use the songLength method to find the length of each song. The following table shows the values returned by songLength for a playlist with 5 songs.
