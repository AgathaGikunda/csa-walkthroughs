Question 1: Name Tags

For each part, you write a code segment (no method header) that uses the variables given and prints the intended output. Your code must work for every example in the table, and for any other values that follow the rules. You may use any method in the Java Quick Reference.

This question involves processing strings of text for printed name tags. Consider the following variables.

  • width is an int variable with a positive value.
  • word is a String variable with a non-null value.
  • otherWord is a String variable with a non-null value.

1a

A code segment, which you will write, should print output according to the following rules.

  • If the length of word is greater than width, print the first width characters of word between two square brackets ("[" and "]").
  • Otherwise, print word between two square brackets, with dashes ("-") on each side so that there are exactly width characters between the brackets. There should be an equal number of dashes on each side of word, if possible. If this is not possible, there will be one more dash on the left side of word than on the right side.
