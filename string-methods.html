String Methods: Which One, and How?

FRQ 1(b) always uses String methods. First meet the methods, then practice: read a scenario, pick the method, and see how it goes inside a method.

Three facts first

Counting starts at 0. The first letter is at index 0.
The last letter is at length() - 1.
Methods never change the String. They give you a new value, so save it or return it.
